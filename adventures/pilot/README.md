# Pilot Adventure: The Silent Colony (working concept)

**State:** Development sketch, not a published adventure.

A Terran frontier expedition investigates a mining facility that has stopped transmitting. A Zerg threat exposes failures in local preparedness and requires investigation, resource management, and tactical responses.

## Test objectives
- Distinct roles for soldiers, technician, medic, specialist and commander without bespoke classes.
- Investigative/social decisions and SWADE Dramatic Tasks / Quick Encounters.
- Ordinary Zerg encounter vs a directed swarm or feral encounter.
- Military weapon and powered-armor benchmarks.
- One vehicle-scale threat or extraction challenge without demanding a full warship combat system.

## Completion requirements
Select starting era and campaign pitch; build representative PCs and 4–6 profiles; supply equipment; run and log outcomes; revise mechanics before comprehensive expansion.
