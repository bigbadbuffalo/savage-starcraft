# Savage StarCraft — Setting Rules baseline v0.1
**Approved by project owner, 2026-10-10.** The small Setting Rules package and **fixed Class for power armor** are approved design decisions. No specific CMC numerical stats have been approved. The power-armor Critical Hit and vehicle-only maneuvering interpretation is also approved. Specific C-14 and CMC equipment statistics remain unapproved.

| Rule | Published source | Project scope |
| --- | --- | --- |
| More Skill Points | SWADE Core p. 140 | Default starting characters: 15 Skill Points |
| Heavy Metal | Sci-Fi Companion p. 93 | Preferred class-based heavy combat, including powered infantry using each suit's **fixed listed Class**; use ordinary character procedures for Wounds |
| Giant Foes | Sci-Fi Companion p. 78 | Normal situational option against qualifying exceptionally large foes |

**Campaign-only options:** Logistics, Energy Management, Downtime, Hacking, Salvage & Trade, Clashes, tactical vehicle combat, Gritty Damage, Difficult Healing and Horror Companion expanded Fear consequences. Hard Choices, Villainous Conviction and Super Powers Combined Attacks are **not** general defaults.

> **Power Armor Classes (Savage StarCraft):** A powered suit has a **fixed Heavy Metal Class printed in its equipment profile**. Use that Class regardless of its current wearer's Vigor, natural Toughness or other personal characteristics. The *Science Fiction Companion* explicitly lists a Title/Class for powered armor (p. 120), and its stock suits have stated ratings (pp. 126–127). This **fixed-model convention is approved**. When creating a new CMC configuration, assign the model's Class during equipment design; changing the wearer never changes it. Reassess a Class when intentionally redesigning a suit's permanent protective configuration, **not** dynamically with the user's Vigor or each passing combat modifier.

**Scope and combat caveat:** Heavy Metal (SFC p. 93) is the approved leading damage method for vehicles and powered combat suits. The first dedicated **powered-infantry** test will compare C-14 Weapon Class to each suit's **fixed** Class and use the printed class-relative Wound outcomes. The project accepts very lethal Marine-versus-Marine combat as a valid design outcome; it does **not** invent a safety buffer solely for PCs. Continue using published character procedures without inventing an additional personal-combat rule. **Approved power-armor interpretation:** If a separately resolved attack leaves the wearer with one or more Wounds, roll **once** on the suit's Critical Hit table, regardless of the number of Wounds that attack caused. Separate independently wounding attacks each trigger their own suit Critical Hit roll. **Vehicle Out-of-Control/maneuvering rolls do not apply to individuals merely wearing powered armor.** This follows the SFC's power-armor wound trigger (p. 120) and the Core vehicle precedent of one Critical Hit roll per damage roll, not per Wound (Core p. 117); it is **an adopted cross-rule interpretation, not verbatim power-armor RAW**. No separate Soak or suit-Wound mechanic is introduced. See `development/benchmarks/HEAVY-METAL-INTERFACE.md`.

**Published RAW versus design choice:** The Companion itself publishes suit Classes, while the process for assigning Classes to *new fictional CMC variants* and handling personal outcomes is a Savage StarCraft conversion/interpretation. The printed Heavy Metal calculation based on total Toughness (p. 93) is expressed for **vehicles**, not as an explicit instruction to recalculate a stock powered suit's Class from each wearer's Vigor.
