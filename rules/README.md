# Savage StarCraft — Rules

**State:** Small Setting Rules package approved. See [Setting Rules](SETTING-RULES.md). Kinetic Foam is separately owner-approved as an equipment Mod, and Firebat heat insulation is provisionally selected; **Protoss shielding and psi progression remain competing drafts**. No automatic global shield or psionic spellcasting rules have been approved.

Rules use the SWADE core engine and selected Science Fiction Companion mechanics where suitable. Candidate priorities: shield behavior, psionics, equipment handling, technology compatibility, and infantry-to-vehicle scale.

Don't import all Companions' optional systems by default; isolate new Setting Rules to their specific fictional requirement. Every rule needs linked lore evidence, SWADE printed-page precedents, expected edge cases and a test.

See [design charter](../development/DESIGN-CHARTER.md) and [conversion template](../templates/CONVERSION-PROFILE.md).

## Protoss candidate traits and powers
- [Basic Telepathy vs trained Psionics](PROTOSS-PSIONIC-PROGRESSION-DRAFT.md): published SFC p.8 1-point Telepathy ancestry for ordinary short-range communication, and SFC p.201 Psyker for trained 3 Powers/10 PP; no universal High Templar ability for all Protoss.
- [Personal Force Field vs charged shields](../equipment/protoss/SHIELD-SYSTEMS-PLAYTEST.md): SFC p.42 ordinary +4 Toughness doesn't reduce direct Heavy Metal Wounds, while p.123 charged Soak system has different resource behavior; no stacked default.
- [Light Duty Zealot chassis](../development/benchmarks/PROTOSS-SUIT-CHASSIS-COMPARISON.md): SFC p.122 negative Mod lets power suit retain strength/motion while losing Heavy Armor quality, as one plausible lore-compatible choice.
