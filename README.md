# Savage StarCraft

A lore-first conversion of Blizzard Entertainment's **StarCraft** setting to **Savage Worlds Adventure Edition (SWADE)**.

**Status:** Foundational policy and research scaffolding. This is an unofficial fan conversion in early development; there are no approved unit statistics yet.

## Approach

Build a **toolbox**, not character classes or an RTS simulator. Occupations such as Marine, Firebat, and Ghost are usually builds composed of ancestry, skills, Edges, capabilities, and interchangeable equipment. Ready-to-run NPC profiles may still exist. A Zerg organism can be designed directly as an adversary using SWADE's creature-design conventions.

Source authority and confidence in an individual claim are different. A measurement inferred from a top-priority cinematic remains an inference; a clearly stated figure in an official reference book may be better dimensional evidence.

The setting must distinguish infantry small arms, specialist anti-armor weapons, walkers, colossal organisms, and spacecraft. No expectation that numerous Marines defeat a battlecruiser by accumulating RTS-style damage.

## Repository layout

- `development/`: charter, roadmap, research protocol, adaptation decisions.
- `lore/`: canon policy, source registry, entries, disputes, timeline.
- `references/`: working source indexes and uncertain measurements.
- `templates/`: standard records for consistent contributions.
- `rules/`: approved character, power, and setting mechanics.
- `equipment/`, `bestiary/`, `vehicles/`: modular game content, created after foundations.
- `adventures/`: practical tests and future Savage Tales.

Git tracks files, not empty directories; sections are populated when their first usable document is ready.
