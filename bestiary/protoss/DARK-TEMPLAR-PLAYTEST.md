# Dark Templar — Nerazim Void-Warrior

**Status:** `playtest`, 2026-10-11, customized relative to Zealot; stealth availability/duration unresolved.  
**Blizzard:** [original Dark Templar guide](https://classic.battle.net/scc/protoss/units/darktemplar.shtml): Nerazim outside the Khala, use **void-shadow powers**, light-bending stealth and modified psi-blades, trained in assassination. Cloaking is not a universal Protoss ancestry ability.

**Dark Templar (Elite Extra or named Wild Card, Size0 Normal Scale)**  
**Attributes:** Agility **d10**, Smarts **d10**, Spirit **d10**, Strength **d10 / d12+1 suited**, Vigor **d8**.  
**Skills:** Athletics **d10**, Fighting **d12**, Notice **d10**, Stealth **d12**, Intimidation **d8**, Psionics **—** unless specialist AB selected.  
**Pace7; Parry8; Toughness14 (4 ordinary Armor +4 field Toughness)** / **10(4)** field inactive.

**Gear and features**
- **Void combat harness:** **+4 ordinary Armor**, suit-assistance to Strength **d12+1** is **custom**, not SFC stock suit bonus; lighter approach than Zealot's +6. A worn personal shield uses candidate A SFC p.42 by default **for initial trial only**.
- **Void Psi Blade:** **Str+d10 / AP8 / HW Class II with suited Strength**, same arithmetic as Zealot's enhanced psi-blade; **not** the SFC standard Psi Blade's ClassI default. No free double attacks.
- **Light-Bending Cloak:** SFC p.42 **Cloaking Skin**, when activated mimics **invisibility** power (SFC Dev III can operate 1 day; Dev II 1 hr). Unlike original StarCraft's "**permanently cloaked**" RTS designation, this published gadget needs a power supply and activation, and detection remains relevant. **Unlimited ongoing camouflage as described in Blizzard lore would require a specifically stronger/recharging variant**, not a free correction of printed battery time. If psychic individual cloak is selected, use Core **invisibility** power with actual PP and skill instead; do not run both for zero price.
- **Ancestral Telepathy:** Same SFC p.8 short-range communication, **not Khala membership**. Optional trained void **Arcane Background (Psionics)** uses actual power/PP/Edge investment rather than all Dark Templar receiving 10 PP plus their cloak automatically.

**Battle role:** vulnerable once detected; stealth enables position and The Drop when the situation actually meets SWADE requirements. Elite blade can harm powered Marine/Firebat/Marauder if it reaches them. Area attacks, scanners and exposed footprints provide counterplay; a cloak need not render every sound, smell and psionic signal invisible.
