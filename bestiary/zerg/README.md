# Zerg Ground Bestiary — First Integrated Playtest Baselines

**Status:** `playtest` **proposals**, built **2026-10-11** using the owner's **shape and physical scale first; unexpected SWADE mechanics second** method. No individual number is `approved` or the result of a played encounter.

**Research / cross-Companion source map:** [Zerg analogues and mechanics survey](../../development/benchmarks/ZERG-SWADE-CREATURE-AND-MECHANICS-SURVEY.md). Each creature has a source-specific and rules-specific rationale. **Scale is SWADE physical creature Size, not SC1/SC2 gameplay's Small/Medium/Large target tag.**

**Core contrast:** ordinary Zerglings, Hydralisks, Roaches, Banelings, and Lurkers have **natural Armor, not automatically Heavy Armor or a Heavy Metal Class**. A Class I C-14 hits them with *rolled damage and AP against natural Armor*. The exceptional Ultralisk has deliberate **proposed natural Heavy Armor / Class III derived from Toughness26**, expressly to model a source-supported living tank shrugging ordinary Marine spikes; treat as an organism-specific `playtest` conversion, not an approved universal organism-class rule.

**Other encounter content:** [Creep & infestation hazards](CREEP-AND-SWARM-HABITAT.md) and [Integrated Zerg encounter/weapon checks](../../development/benchmarks/ZERG-INTEGRATED-PLAYTEST-CHECKLIST.md). Do not turn adult Zergling mobs into Core Tiny-Vermin Swarms: use individual Extras and normal Gang Up.

**Additional strains not yet statted:** Drone, Queen, Ravager (Zerg unit, distinct from SFC's unrelated creature named Ravager), Infestor, Mutalisk, Overlord, Broodling, Corruptor, Nydus Worm, and older strain variants. Lack of a complete set does not block provisional combined-arm tests; build these as the surrounding packet requires.
