## Add-a-source instructions
Create a stable ID (e.g. `SC-NOVEL-LIBERTYS-CRUSADE`); record author, work title, publication/version date, format, publisher, localization if relevant, official access URL or owned hardcopy, default tier, and whether it has actually been consulted. Never write a guessed page locator.

Register new sources here; document specific factual claims in lore entries or disputes. Record exact quotations only as short excerpts where necessary and appropriate; prefer paraphrase with locators.
